# Aset Pijarkan Cita

Ekspor file sesuai format pada tabel, lalu simpan di `assets/` dengan huruf kecil dan ekstensi yang sama persis. Setelah itu, buka ulang atau refresh `pijarkan-cita.html` dan scroll ke bagian yang memakai aset tersebut. Website membaca nama ini otomatis.

## Aset yang bisa ditambahkan

| Nama file | Letak | Ukuran yang disarankan |
| --- | --- | --- |
| `foto-header.webp` | Latar bilah navigasi pada ketiga halaman | 1400 × 240 px |
| `foto-pembuka.webp` | Latar pembuka halaman Pijarkan Cita | 1440 × 720 px |
| `foto-makna.webp` | Latar bagian Apa itu Pijarkan Cita? | 1440 × 900 px |
| `foto-tiga-pilar.webp` | Latar bagian Tiga Pilar | 1440 × 900 px |
| `foto-visi-misi.webp` | Latar bagian Visi Misi | 1440 × 1000 px |
| `logo-pijarkan-cita.png` | Logo di kiri navbar dan logo utama di tengah bagian Arti Logo | 640 × 640 px, transparan |
| `logo-simbol.png` | Ikon Simbol Teknik Industri | 128 × 128 px, transparan |
| `logo-nyala.png` | Ikon Nyala Api Merangkul | 128 × 128 px, transparan |
| `logo-lengkung.png` | Ikon Lengkung Landasan | 128 × 128 px, transparan |
| `logo-pijar.png` | Ikon Pijar Menjulang | 128 × 128 px, transparan |
| `logo-bintang.png` | Ikon Dua Bintang | 128 × 128 px, transparan |
| `siluet-kuning.png` | Siluet yang bergerak saat scroll di halaman Pijarkan Cita | 640 × 640 px, transparan |

Foto latar dipotong mengikuti area tiap bagian. Letakkan subjek utama dekat bagian tengah agar tetap terlihat pada ukuran HP. Gunakan latar transparan untuk logo, ikon, dan siluet sesuai tabel.

## Aset yang sudah ada

Ganti file dengan nama yang sama jika kamu punya versi baru.

| Nama file | Letak |
