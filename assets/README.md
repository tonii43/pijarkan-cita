# Aset Pijarkan Cita

| Nama file | Posisi di website |
| --- | --- |
| `logo-kampanye.png` | Kiri atas banner. Gunakan PNG berlatar transparan. |
| `foto-marvin.webp` | Foto Marvin di kanan judul. Posisi foto bisa diatur di `campaign.config.js`. |
| `cover-narakarsa.webp` | Pratinjau sampul di dalam kartu **NaraKarsa dari Pijarkan Cita**. |
| `elemen-1.webp`, `elemen-3.webp` | Ornamen kampanye di sekeliling bingkai foto Marvin. |
| `baskerville-bt-italic.woff2` | Opsional. Gunakan file webfont yang kamu punya lisensinya, lalu isi `baskervilleFont` di `campaign.config.js`. |
| `grand-design.pdf` | Opsional. Bisa ditautkan dari `campaign.config.js` lewat `./assets/grand-design.pdf`. |
